# 舞台视觉预设 v1

场景编辑器 `/editors/scene.html` 支持保存到浏览器、恢复、JSON 导入导出及恢复默认视觉。刷新后不会自动覆盖默认值，点击“恢复保存的预设”恢复；恢复默认不会删除保存值。浏览器存储按站点隔离，建议导出备份。

## 运行时使用

```ts
import { createStage, parseVisualPreset } from 'nijimi';
const stage = createStage(container, {
  pack: myScene,
  withCharacter: false,
  visualPreset: parseVisualPreset(savedJson),
});
const snapshot = stage.visual.capture();
stage.visual.apply(snapshot);
stage.visual.reset();
```

`savedJson` 是已解析的 JSON 对象；字符串先 `JSON.parse()`。启动预设在创建 GPU 资源前校验。`reset()` 恢复舞台创建时的内建视觉基线（包括 URL 中的 NPR 初始模式），不会恢复传入的自定义预设。若要恢复自定义值，请再次 apply。

## 范围

包含舞台自有的主光、暮光、补光、半球光、环境光，颜色/强度/相关位置与主光目标；环境反射强度、曝光、NPR 开关、Bloom 参数与开关、调色参数。颜色使用 sRGB `#RRGGBB`，由适配层转换。数据不持有 Three.js、DOM 或 GPU 对象。

不包含相机、画质、环境贴图本体、内容包灯光、角色光台架、模型、材质参数、演出、背景和整个场景。它是同一舞台基线下的灯光与后期快照，不是跨环境完整画面复现格式。镜头与标定属于后续 P2。

NPR 开关只切换材质处理，和显式环境反射强度分别记录；原有 `stage.setNpr()` 保留旧环境强度默认行为，应用预设时以预设的环境强度为准。

## 数据与失败行为

- `version: 1`；必需字段、类型、颜色、有限数与范围完整校验，拒绝未知字段与版本。
- 校验全部通过后才写入舞台，无效配置不会局部改变灯光。
- capture 和 apply 都重建独立数据，不共享坐标数组。
- 编辑器文件上限 64 KB；导入不会自动写浏览器存储。
- 保存失败、无保存值或导入失败会显示原因，不能用成功提示掩盖错误。
- 编辑器现有环境冷底滑杆同时调整半球光和环境光；导入可保存两者独立值，下次拖动该滑杆会重新按原比例联动。

## 检查

`npm run check:visual-preset` 检查真实灯光/调色适配、JSON 往返、独立快照、非法输入原子拒绝与默认恢复。GPU 编译和交互需另外在浏览器验证。
