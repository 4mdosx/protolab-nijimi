## 本轮开发范围

完成 P0 的现有命令检查和 P1 的最小端到端闭环。P1 包含舞台自有灯光颜色/强度/位置、曝光、Bloom 参数/开关、NPR 开关、环境反射强度与现有调色参数；不承诺保存内容包灯光、资产、演出、相机、画质或整个场景。

运行时默认值保持原样；可通过 StageOptions 指定预设。编辑器导入/恢复必须完整校验后应用，失败显示原因；本地保存失败不伪报成功。沿用现有 ScenePack、材质扩展与冻结表情契约，不增加通用编辑器或组件框架。
